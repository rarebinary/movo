## 2026-08-11 visual verdict

| Criterion | Result | Evidence |
| --- | --- | --- |
| Preview dominance | Pass | Media now occupies the entire clipped window canvas. |
| Outer-canvas continuity | Pass | No toolbar/body or side-rail color seam remains. |
| Control consistency | Pass | Circular optical icons, capsule selectors, graphite wells, and chrome primary action share one family. |
| Chrome restraint | Pass | Chrome is limited to the mark, current selection, selected segmented state, and primary action. |
| Apply-target clarity | Pass | `Both / Desktop / Lock Screen` and display selection live in the action-anchored popover. |
| Minimum-window integrity | Pass | Screenshot shows all primary controls without clipping at the supported minimum family. |
| Accessibility structure | Pass with follow-up | Computer Use exposes every primary control and target choice; dedicated VoiceOver and Increased Contrast passes remain in the roadmap. |

The redesign intentionally keeps Movo's single-workspace topology. It borrows immersive media hierarchy and compact control grammar from the archived references without reproducing Wallspace's navigation, branding, assets, catalogue, or exact screen structure.
